PIANOSCALIER

SAE 303 — Création d'application interactive (IoT) // Projet d'équipe (5 étudiants) // Janvier 2024
Un escalier transformé en piano géant.

Et si monter un escalier devenait un jeu ? Le Pianoscalier transforme un escalier ordinaire en instrument de musique : chaque marche détecte votre passage grâce à un faisceau laser et déclenche une note. Derrière la magie, un système complet qui mêle électronique, un serveur Node.js et une interface web en temps réel pour reconfigurer les sons à la volée.

// Mon rôle dans le projet

Un projet mené en équipe, à cinq. Je me suis impliquée sur toutes les étapes : la conception et l'écriture du code, le montage et le câblage du dispositif, ainsi que la réalisation des vidéos — une participation de bout en bout, de l'électronique à la production.

Le concept

Dans le cadre de la SAE 303 « Création d'application interactive », le défi était de concevoir de A à Z un objet connecté piloté par une application web. Parmi les sujets proposés, nous avons choisi en équipe de relever celui de l'escalier-piano — un classique qui paraît simple, mais qui cache une vraie chaîne technique : capter un pas, déclencher un son, et rendre le tout configurable depuis le navigateur. Une semaine de développement intensif (24h) pour passer de l'idée au prototype fonctionnel.

Comment ça marche

01 — DÉTECTION

Laser + photorésistance

Chaque marche possède un laser pointé sur une photorésistance (LDR). Quand un pied coupe le faisceau, la luminosité chute brutalement : l'Arduino détecte le pas instantanément.

02 — AUDIO

Module MP3 DFPlayer

L'Arduino pilote un module DFPlayer Mini qui lit le son associé à la marche depuis une carte micro-SD, puis l'envoie vers un haut-parleur.

03 — CONTRÔLE WEB

Node.js + Socket.io

Une interface web dialogue avec un serveur Node.js qui relaie les commandes à l'Arduino par liaison série. On réassigne les notes en direct, sans retoucher au code.

L'explication technique en détail

Tout le projet est documenté dans notre compte rendu : schéma de câblage, installation, et surtout les choix de code que nous avons faits et justifiés. En voici les points clés, puis le document complet.

arduino / Piano-stairs.ino

Le firmware

  • Deux ports série séparés : USB à 115200 bauds (PC) et SoftwareSerial à 9600 (module MP3), pour éviter les conflits de données.
  • Détection de changement d'état : le son n'est joué qu'une fois par appui, au lieu d'être relancé des centaines de fois tant que le pied reste posé.
  • Config dynamique via le protocole M{marche}:{piste} — changer les sons sans re-téléverser le code.
server.js

Le middleware Node.js

  • Le navigateur ne peut pas accéder au port USB (sécurité) : ce serveur fait le pont.
  • Socket.io maintient un canal ouvert en permanence — pas de rechargement de page.
  • Il convertit le JSON {step:1, track:5} en chaîne optimisée M1:5 envoyée à l'Arduino.
index.html

L'interface web

  • Génération procédurale du DOM : passer de 4 à 20 marches = changer une seule variable.
  • Un dictionnaire noteToTrack traduit le musical (« Do2 ») en piste machine.
  • Des presets reconfigurent toutes les marches d'un clic (ex. « Rat Dance »).
